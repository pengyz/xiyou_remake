# commit 实证贴件三纪律（claims-must-match-content 治理）

1. **原文贴**：message 内每个 sha/计数=命令输出原文，禁手抄（批 1-2 四次超实病灶）；
2. **禁手粘**：实证段由命令输出重定向生成（`$(cat /tmp/evidence.txt)`），禁手编辑粘贴
   （批 3 快审：粘贴本身被手编辑=17≠20 行）；
3. **终态贴**：贴件必须描述**提交树终态**（从提交树重跑取），过渡态贴件=paste 真/commit 假
   （批 5-a：method_reach 改名过渡态贴件与终态矛盾）。

## 命令侧加工边界（合规线三则）
整行选择/排序/过滤（grep/sed/awk 输出重定向）=**合规加工**，条件：
①命令入档（可复跑）②不改行字节 ③不隐匿不利输出。
**手编辑行内容/sed 改写行内容=违规**。

## 引锚纪律
引 a.java 行锚必跑 `sed -n 'X,Yp'` 实文随贴、行数从输出数（批 1-3 锚漂移惯犯止血）。
