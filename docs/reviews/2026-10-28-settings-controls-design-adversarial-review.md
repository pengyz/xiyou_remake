- **overlay kind 4**：只有报价型（flags&2）才区分接受和拒绝；其余告示类 -5 与 -7 同效（关框）。

## 5. 被推翻的复核意见：M7 / BUG-007

- 复核者 B 依据 BUG-007 称"标题'设置'进的是关于页"。核实结果相反。
- 标题项文字不是 `MENU_LABELS` 文本，而是美术条 menu[1]（68×102，6 行×17px）按 `17 * kind` 取行（title.rs:470/495）。
- 该图六行依次为「开始游戏 / 继续游戏 / 设置 / 帮助 / 关于 / 退出」，正好对应分派 kind 0..5 → mode 14/8/16/15/17/22（title.rs:383-396）。帮助、设置、关于三页自身的标题条也按同一图取行：sy=51/34/68，即第 3/2/4 行。
- 结论：标题文字与动作一致。BUG-007 的"文字-动作错位"是把标题文字误当成 `MENU_LABELS[kind]` 得出的，疑似误诊，须按 AGENTS §3.6 原地更正（A 级：资源图 + 绘制代码）。
- 对本设计的影响：「设置」入口就在标题第 3 项。
