# 触屏原生操作 + 操作级回撤 实施计划（touch-native-undo）

> 2026-10-23。用户裁定：A（路径遇敌**自动战斗续走**，魔塔手游范式）+ **操作级回撤**
> （回撤单位=操作：走过去+战斗=2 笔，按一次回撤战斗、再按一次回撤位置）+
> a（**战斗终结才入栈**，战斗中途不可撤）。业界范式参考：魔塔-还原经典"触碰寻路
> 无需操纵杆"、魔塔大冒险"全屏触控+遇敌自动战斗"、TapTap 格子寻路文章（门/NPC/障碍）。

## 0. 设计决定总账

| 决定 | 内容 |
|---|---|
| 操作模型 | 点哪走哪（A* 寻路）+ 点交互物=走近+交互（碰撞语义复用）+ 手动输入即打断寻路 |
| 回撤单位 | 操作（journal LIFO 逆放）：位移 1 笔、战斗 1 笔、拾取/开门 1 笔（独立） |
| 战斗入栈 | 战斗**终结才入栈**（敌我状态 delta 记录）；战斗中途不可回撤 |
| 边界 1 | **换层/存档点/脚本事件触发 = 清栈**（不可反转的副作用不进回撤域——v1 务实边界） |
| 边界 2 | 对话/商店/背包使用=独立操作可回撤（消耗型决策反悔） |
| 边界 3 | 回撤触达=画面常驻"撤销"按钮（可回撤 N 步可视化）；物理 BACK 语义不动（-7 保真锚） |
| 双模并存 | **移动按键保留**（既有 DpadZone/SoftZone 一等公民）+ 点击移动——两套并行，不是替代（2026-10-23 用户裁定） |
| 打断规则 | **寻路中任意输入皆打断**：触屏点击/滑动/方向按键/软键全通道（用户裁定） |
| 隐藏墙双通道 | **方向按键踏步撞墙 或 触屏点墙/滑动探步入**皆可开隐藏墙（两通道等权） |
  > 【2026-10-30 更正 · STAGE-B-008】点墙 = 探步、点地 = find_path 的壳层分类已由 core `tap_cell`（安全通行 BFS、走到邻格再撞、怪物先选中）取代，
  > 见 docs/superpowers/specs/2026-10-29-dual-control-schemes-design.md §5。"打断规则 = 全通道打断"同批收窄为仅按键通道（点按 / 滑动由 core 排队）。 |
| 兼容层 | 滑动=方向踏步（撞墙即停，后置可选） |

## 1. 架构（分层：映射在壳、逻辑在核、保真面零污染）

```
shell（android/win）：触点→格坐标（视口/相机反变换）+ 撤销按钮 UI
   ↓ 抽象动作层（新增，Stage B 加法）：WalkTo(tile) / Undo
game-core：A* 寻路（可走性格图，纯函数）→ 喂 walkPathBuffer（机构现成 enums.rs:68）
   ↓ 行走推进 → 撞击/拾取/开门触发 → 每笔操作入 undo_journal
undo_journal（新模块）：LIFO delta 栈（位移/战斗/拾取三型逆操作）
```

**保真红线**：classic 面零漂移——key 行为链（press_key/release_key/撞击臂/战斗表）
一行不动；WalkTo/Undo 是**新增入口**，金样/oracle 不经过；回撤反转只改状态副本，
不改任何推进语义。

## 2. undo_journal 三型操作（delta 逆操作）

| 型 | 正向 delta | 逆操作 | 入栈时机 |
|---|---|---|---|
| 位移 | 起点→终点 | 位置回起点 | 寻路整段结束（打断=按实际终点入栈） |
| 战斗 | 敌灭+玩家血/金/经验/掉落 | 敌复活原血+玩家字段回滚 | **战斗终结**（中途不入栈=不可撤） |
| 拾取/开门 | 道具/钥匙/门状态 | 退回道具+门复锁 | 立即 |

**清栈事件**（边界 1）：换层（changeFloor/LAY/传送）、存档、任何 MOV/脚本事件格触发
（宝箱/陷阱/剧情/开关）——触发即清，v1 不做脚本副作用反转（诚实边界）。

## 3. TDD 判据（红先行）

1. A* 寻路：直线/绕障/不可达/斜向禁走四例；路径连续性（相邻格）断言；
2. WalkTo 链：tap 格→walkPathBuffer 推进→终位断言；途中撞敌=挂起→战斗终结入栈→续走；
3. **回撤序列判据**（用户语义原样钉死）：点按走过去+1 战 ⇒ 回撤 1 次=战斗复原（敌活/血量/
   金币逐字段）⇒回撤 2 次=位置回起点；LIFO 序三笔组合逆放；
4. 清栈判据：寻路中触发脚本格 ⇒ 栈清；换层 ⇒ 栈清；战斗中途 ⇒ 不可撤（journal 无战斗笔）；
5. classic 零漂移：oracle/金样/op 串照绿（回归锚）。
