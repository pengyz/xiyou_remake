## 2. 保真红线辨析（v2 修正版）

### 2.1 逻辑/视口分离（沿 v1 结论，边界补清【V3】）

**夹具协议（V3）**：帧夹具（frames.txt）与格坐标/脚本坐标**锚定逻辑坐标系**（240×320）；
**视口显式注入**——夹具生成/回放须显式声明视口参数（防 Layout 误值洗期望）；
**重生成红线**：视口变更不得触发夹具期望重写（期望=240×320 基线冻结）。
表述两分：**格坐标**（脚本/格语义，逻辑系）vs **渲染-相机坐标**（视口系）——脚本坐标不移植。

### 2.2 金样两档策略【v2 更正 V1：v1"分辨率无关共用"证伪】

- **共享子集显式清单（V1）**：state_dump 倾印含**视口耦合字段**（cameraPixelX/Y、
  viewWidthPx、playerPixelX/Y——state_dump.rs:88-96）⇒ 两档金样**共享子集** =
  逻辑状态字段（HP/楼层/实体表/flags/道具栈/…）逐字节共用；**视口耦合字段按档各自基线**
  （显式字段清单在 2c 实施时枚举并冻结）。
- **tick 锚不移植**：脚本 tick 相机门（dialogPhase=4 AwaitCamera 收敛距离=f(视口)）⇒
  含相机门的 tick 时序锚**分辨率耦合**，跨档不共用（保真档内自洽）。
- **2c 视口基线 = 自证基线（非差分）【V1 修正】**：480×640/720×1280 两档基线是
  **冻结当下行为的自证基线**（非"与 240×320 差分等价"）；**机械等价**另立 property：
  2x 帧 = nearest 整数放大（逐像素 property 化断言）+ **跨档等价契约**（共享子集逐字节）；
  **用户截图验收**（无头截图集供用户选定，C4）。

### 2.4 零行为差证明策略【v2 补③-1/③-2】

- **per-constant 等值断言**：每个 const 重锚后断言 240/241/320/321（**奇/偶视口**）下
  取值等价（240×320 保真档=原值逐字节）；

  不"规整"——③-2）；
