# 玩法规则行为合同（战斗 / 移动 / 道具 / 门 / 商店 / 场景触发）

> P2 产物，模板见 [prompts/spec-writer.md](../../prompts/spec-writer.md)。每条规则带证据指针与可判定性；
> 结论分「已证实 / 假设」两节（AGENTS.md §3 证据纪律）。原版可疑行为以 `BUG-xxx` 引用
> [docs/bug-ledger.md](../bug-ledger.md)（未立案的给出建议编号，交 Lead 决定立案）。
>
> **一句话结论**：游戏是 32px 网格、确定性回合制的「推图解谜 + 数值 RPG」。战斗全程无随机数
> （RNG 仅 1 个取值点且不进伤害公式，见 [state-machine 考证](../findings/state-machine.md) §6）：
> 损血可由攻防数值精确预测；**开战前有硬门槛**（预计损血 ≥ 当前 HP 或攻不破防则拒绝战斗），
> 玩家受击不会致死（HP 下限 1），因此「死亡」不是本作的失败判据，**卡关才是**。
>
> **考证方法**：对 [reference/seed/a.java](../../reference/seed/a.java)（CFR 反编译 8457 行）做静态
> 方法级精读（战斗结算、碰撞交互、道具生效、商店交易、踩格效果五大入口）＋ `analysis/ex/sprite*`
> 字节级抽查（实体类型分布）交叉验证；C 级猜测一律收入「假设」节。字段名受 CFR 同名重载影响，
> 引用时均给出方法与行号双重定位（见 [script-dsl 考证](../findings/script-dsl-semantics.md) 遗留问题 6）。

## 已证实

### A. 战斗公式与结算顺序

### R-battle-1: 单次伤害 = 玩家有效 ATK − 敌 DEF，敌人反击 = 敌 ATK − 玩家 DEF（无随机、无命中率）
- 证据: `reference/seed/a.java:7721-7733`（战斗 tick `c(boolean)`：`n = this.f(a2) - this.u[a2-41]` 扣敌 HP；
  `n = this.t[a2-41] - this.L; if (n > 0) this.J -= n` 敌反击扣玩家 HP）
- 可判定性: 机器可判定（每 4 tick 的 `bU`/`J` 增量可由 trace 逐 tick 比对）
- 关联: 常量表「敌人数值表」（`t/u/v` = 基础表 `q/r/p` × 难度系数，见 R-battle-5）；无 BUG

### R-battle-2: 结算顺序固定为「玩家先手 → 敌人存活则同回合反击」，每 4 帧完成一个回合
- 证据: `reference/seed/a.java:7724`（`if ((this.bV & 3) == 0)` 每 4 个战斗 tick 才结算一次）、
  `a.java:7726-7733`（`if (this.bU > 0) { 反击 } else { 死亡分支 }`——敌人当回合死亡则**不再反击**）、
  `a.java:7782`（`++this.bV` 每 tick 计数）；战斗 tick 由 mode 3 子状态 `l==5` 每帧驱动（`a.java:1743-1745`）
- 可判定性: 机器可判定（`bV`/`bU`/`J` 的逐 tick trace）
- 关联: R-battle-3（预测公式与本条严格同构）

### R-battle-3: 战前损血预测公式：`loss = max(0, 敌ATK−玩家DEF) × (回合数 − 1 + (0 | 1))`，回合数 = ceil(敌HP / (玩家有效ATK − 敌DEF))；攻不破防返回 −1
- 证据: `reference/seed/a.java:7699-7711`（静态 `a(n,n2,n3,n4,n5,bl)`：`n7 = n3/(n-n5)` 进位取整；
  `n6 = (n4-n2)*(n7-1)`；`!bl` 时补加一次反击；`n <= n5` 时返回 −1）、
  `a.java:7683-7686`（入口 `a(int n, boolean bl)` 传参：有效 ATK / 玩家 DEF / 敌 HP(`v`) / 敌 ATK(`t`) / 敌 DEF(`u`)）
- 可判定性: 机器可判定（预测值与 R-battle-1/2 实际结算结果恒等式可断言）
- 关联: `bl=true`=玩家先手战（扣 `回合数−1` 次），`bl=false`=敌人先手战（多挨 1 次，见 R-battle-6）

### R-battle-4: 开战硬门槛：预测损血 < 0 或 ≥ 当前 HP 时拒绝开战并提示「你无法战胜它」
