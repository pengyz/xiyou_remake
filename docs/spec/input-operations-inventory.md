## 9. 缺口汇总（纯触屏无法完成的操作）

1. 打开游戏内菜单（−7）、打开背包（−6）。
2. 进入 / 退出探索模式，探索中平移视角。
3. ○/× 回答：道具使用确认、商人报价。
4. 从任何列表 / 页面返回：存档、设置、帮助、背包、怪物图鉴、记录、炼丹炉、读档、片头跳过。
5. 炼丹炉全部操作。
6. 翻页：帮助、怪物图鉴、记录、提示框、对话回翻。
7. 撤销可发现性；点地的各类反馈。
8. 筋斗云（两种方案都不可达，归 BUG-037）。
