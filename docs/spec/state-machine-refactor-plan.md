# 状态机解耦方案（lead 稿，独立复核后实施）

> 【2026-17】基于 state-machine-survey.md（普查）+ dispatch-shape-survey.md v2（表设计）。
> 流程：普查→本方案→独立复核→实施（用户裁定）。

## 0. 核心判定（普查实证）

**状态机的"大"=特例混装，不是状态结构**——壳薄（tick_menu 系 3-7 臂×1-6 行），
厚块 4 处（tick_dialog dialog_phase 臂 48 行/tick_entity_route route_phase 臂 57 行/
walk_phase 臂 46 行/paint cat8 93 行）全是"状态壳+floor 特例/道具特例/恢复特例混装"。

**解耦策略=三轻件组合（不动状态结构）**：

| 件 | 内容 | 量级 |
|---|---|---|
| **A. GameMode 枚举补全** | 15+ 值全枚举（4/5/7/8/9/10/12/15/16/19 十活跃态出 Unknown）+Unknown(i32) 保真兜底保留 | 0.5 天 |
| **B. 厚块特例抽表** | 4 厚块内特例混装→规则表（与 v2 表设计批步 3 同源同法，**合并执行**） | 并入 v2（省 460s×N 金样墙钟） |
| **C. 键码约定文档化** | key_value 26 处全 edge 消费契约+跨态键码约定（-7/-6/-5/-1/-3 语义表）入注释锚 | 0.5 天 |

**明确不做**（普查结论+对照体红线）：
- ❌ 转移表化（(mode,key)→action 表=破坏 run/m_000 case 逐值对照性，与不拆
  execute_script_instruction 同列）
- ❌ HSM 大拆模块（壳薄无收益，拆=搬家不减复杂度）
- ❌ 事件 enum 统一（各态动作不同，26 处收口=大动作小收益）

## 1. 件 A：GameMode 枚举补全（独立小步先行）

**现状**：GameMode 枚举 9 值、10 活跃态落 Unknown(i32)（type-safety 缺口+match 兜底散点）。
**方案**：枚举补全 15+ 值（普查 §1.1 逐值表+三 case 树锚：run/m_000/paint），Unknown(i32)
保真兜底**保留**（未观测值=D4 不发明）；所有 match 点改全枚举+Unknown 臂=现行为逐字节。
**验证**：金样 --check 55 场景+252 测试；**零行为差**（枚举=类型层不动语义）。

## 2. 件 B：厚块特例抽表（并入 v2 表设计批）

4 厚块内特例（floor 特例/道具特例/恢复特例/渲染特例）抽入规则表——**与 v2 表设计批
步 3 消费替换同源同法合并执行**（同一表基建、一次回归墙钟）。壳与转移结构不动。
细化按 v2 schema（RespawnRule 三要素/BossHook 枚举/restore_rules 已落）。

## 3. 件 C：键码约定文档化

key_value 消费契约（edge 语义：press 置值覆盖取末→tick 分支消费→尾清 0，a.java:4270/4276）
+ 跨态键码约定表（-7 返回/-6 确认/-5 战况/-1 上移/-3 …）入 scene.rs 头注释+知识库；
26 处消费点注释锚（归属状态+动作摘要）。**零代码改动**。

## 4. 执行序与验证

```
件 A（0.5 天，独立先行）→ 件 C（0.5 天，随件 A）→ 件 B（并入 v2 表设计批）
每件：金样 --check + 252 测试 + 全闸；枚举补全=低风险、特例抽表=v2 步 3 等值单测护航
```

## 5. 与 v2 表设计的关系

本方案**不替代** v2（数据驱动表设计）——互补：v2 管实体/物品数据化，本方案管状态机
结构清晰化（枚举/契约/特例归位）。合并点=件 B 与 v2 步 3 同批执行。

## 6. 风险与红线

- 保真红线：枚举补全不发明语义（Unknown 兜底保留）；特例抽表值=原版常量（evidence 列）
- 对照性：枚举逐值锚 a.java 三 case 树；转移结构不动（对照体完整）
- 金样：每件 --check 逐字节

## 7. 【独立复核吸收】6 条件（state-machine-refactor-review.md 83ce6df，判定=有条件通过）

  比较（非 match）。
- 真实工作=**全量接线**：补 10 枚举值+字段改型 40 写点+26 比较点+边界 from_raw（载档/trace/
  preset 注入）+序列化 raw()——**非 0.5 天**，重估 1.5-2 天。
- **反例记录**：照字面补完 enums.rs 就收工⇒金样 55 场景全绿但 type-safety 缺口原样在

- **验证三件**：① Unknown(i32) 路径 RED 测（现状 0 测试）② **变体↔a.java case 号映射表**
