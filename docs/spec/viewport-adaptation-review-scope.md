## 六面攻击结果与条件

**① Phase 1"已达成"= 实现属实、验收缺位**。核实：`Viewport::fit/to_screen/blit/Pacer` 确在
（crates/game-desktop/src/view.rs:19/27），4 单测在（含 1920×1080 信箱/边角反映射/信箱外 None）。
但：(a) 无端到端验收物——480×640 blit 输出金样本可机械生成（blit 确定性）却无；
(b) §0.4"补触控=小改"与工时表"2-3 天"自相矛盾；(c) `to_screen` 是**单点映射**（签名
`Option<(i32,i32)>`），"安卓触点直接走 to_screen"未处理多点并发（D-pad+软键同按）；
(d) 窗口 <240×320 时 scale=1 左上裁切不可玩（view.rs:13 自述）——分屏/折叠屏小窗缺口未计。
**条件 C1**：Phase 1 表述降级"已实现（桌面侧）/未验收"，补 blit 输出金样+真窗口记录；
触控范围清单化（见③）。

**② 工时数字零依据 + 2c 金样来源未声明（循环自证风险）**。2a 3-4d/2b 3-5d/2c 1-2d 无参考基准；
实测锚点：金样 prologue 单测 debug **460s**（实跑）、ratchet 261 项、每提交 pre-commit 全量
release 测试（观察 ~2-5 min/次）——2a"102 const+57 散点"按小步提交纪律 = 20-40 提交×闸门墙钟，
3-4 天仅"集中改+一次闸"成立。**2c 的"视口基线生成后冻结"未说生成者**——Java 只有 240×320 输出，
480×640/720×1280 **无差分参照**，只能 Rust 自生成自冻结=防回退不证正确。"Phase 3 可不做"：
20:9 实测 1080×2400 上 4x=960×1280+上下各 560px 黑边——"覆盖安卓主流"仅指可玩，用户诉求
恰只有 Phase 2 解决。**条件 C2**：工时补依据（回归墙钟+提交数）；2c 明标"自证基线（非差分）"+
机械等价补强（2x 帧=240×320 帧 nearest 放大可 property 化）+用户截图验收。**C3**：
Phase 3 搁置条件化（仅当 Phase 2 达成+用户验收后），小窗裁切登记已知限制。

**③ click_code 雏形属实，触控语义缺口大**：现热区仅软键栏三分（main.rs:839-845+测试 :1509）。
缺：⑴**行走=key_held 连续态**，tap-only 无法走路（需 touch-down/up 合成 press/release+
长按保持）；⑵ translate_key **故意丢弃 repeat**（:1486 测试钉死）——触控长按须对齐此语义；
⑶ D-pad/49/55 楼梯键无热区；⑷ 系统 back 是系统事件非"全屏手势"；⑸ 多点并发模型。
**条件 C5 的输入清单**并入 2-3 天重估。

**④ 排期耦合欠硬化（风险已兑现）**：文档仅"建议协调"。实测：并行期 git index.lock 等待
30-180s 多次；**复核进行时（2026-10-17）全量闸门红**——game-core audio/enums/paint/scene/
script+tests+game-desktop main.rs 十文件同 M、cargo test --no-run E0308 编译失败=三线并行现状。
比墙钟更硬的是文件冲突面：2a 散点 57 行中 **41 行在 scene.rs=状态机改造同文件**。
**条件 C6**：2a 与状态机批**串行**（状态机先行，机械归位随后 rebase 最便宜）+三线提交闸门
排队策略+总墙钟预算。

**⑤ 安卓壳漏面清单**（调研仅输入+缩放）：生命周期（onPause 保存/进程死亡恢复——联动
SKY_WAR 存档系）、旋转/竖屏锁、音频焦点+音量键、scoped storage 存档路径（API29+）、
刘海屏安全区×信箱叠加、屏幕常亮、APK 签名/SDK 目标、系统 back 语义；平台 trait 壳侧实现面
未列名（game-platform 现仅 GameClock/GameRng 公开）；**game-wasm 不存在**（注释仍称
desktop/wasm）——若在路线，视口工作量是否双份未答。验证策略须声明：触控映射纯函数化单测
（click_code 体例）+模拟器无头 smoke（遵守"验证不打扰"）。

**⑥ 验收判据全文缺失**：无一处定义"一屏多少格=够"。硬上限（A 级）：**55 图=54×26×26+
1×24×26 格**（maplv 头解析）⇒ 画布 832×832，顶格=26×26 全图；当前可视≈7.5×7.9 格。
**条件 C4**：格/屏目标阶梯（10×13/15×19/26×26）+无头截图集供**用户选定**（AGENTS §5：
产品体验由用户人工试玩反馈）；≥地图尺寸档相机=全图居中语义并入 2b 考证清单；
**必须声明阶段定位：视口扩展改变玩家信息量=Stage B 现代化**（D2），Stage A 判据仍 240×320
金样，或取得用户显式豁免。
